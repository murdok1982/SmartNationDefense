# STANAG 4774 / 4778 Compliance Status & Reference Implementation

**Standard:** NATO STANAG 4774 (Confidentiality Metadata Label Syntax) & STANAG 4778 (Security Metadata Binding)  
**Implementation Classification:** Reference Implementation / Experimental Prototype  

---

## 1. Classification Markings & Hierarchy

The system defines hierarchical clearances enforced on backend routes:
- `OPEN` (Level 0)
- `RESTRICTED` (Level 1)
- `CONFIDENTIAL` (Level 2)
- `SECRET` (Level 3)
- `TOP_SECRET` (Level 4)

Support for TLP tagging:
- `TLP:CLEAR`, `TLP:GREEN`, `TLP:AMBER`, `TLP:AMBER+STRICT`, `TLP:RED`

---

## 2. Binding Mechanism Status

| STANAG Requirement | Implementation Status | Technical Mechanism |
|---|:---:|---|
| **Confidentiality Metadata (4774)** | `IMPLEMENTED` | Structured Pydantic classification metadata bound to intelligence models. |
| **Cryptographic Binding (4778)** | `PARTIAL` | Payload SHA-256 hash anchored in audit chain. Ed25519 signature verification supported via JWS endpoints. |
| **mTLS Transport Binding** | `PLANNED` | TLS termination supported via Nginx reverse proxy; internal mTLS planned for federated nodes. |

---

## 3. Verified Limitations

1. Autonomous edge nodes currently rely on pre-shared keys (PSK) or JWT bearer tokens for payload verification rather than full PKI X.509 attribute certificates.
2. Full automated NATO cross-domain guard federation is experimental.
